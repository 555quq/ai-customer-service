# v1.0.0 发布说明

发布日期：2026-08-26

## 范围

- Docker-first 单客户自托管标准版。
- 管理端、客服端和 Widget 的统一 Bridge API 与鉴权边界。
- Chatwoot 转人工闭环、Qdrant 增量知识库任务。
- 一键安装、备份、恢复、更新、回滚和诊断脚本。
- Prometheus 业务指标、默认告警和预置 Grafana 仪表盘。
- 可选 Dify 增强版 overlay，标准版默认不依赖 Dify。
- Stock Chatwoot 3.11 私有 Webhook Gateway、Redis AOF 队列、HMAC v2 Worker、Bridge 幂等和 Setup 自动注册。
- P4-B 单 Worker 并发池：默认并发 8、每会话 FIFO、有界缓冲、Redis 单实例租约、Pending 恢复和并发可观测性。
- Admin/Agent 角色独立 Refresh Cookie、Setup v2 Agent 强凭据和 Admin 凭据轮换入口。
- U1 生产入口：四子域名 Caddy HTTPS、Admin/Chatwoot CIDR 白名单、Widget 精确公开路由、回环端口绑定和生产安装门禁。

## 兼容与数据

- 发布版本：`1.0.0`。
- 备份与诊断报告 schema：`1`。
- Dify 增强版联调基线：`1.16.1`，由每个客户独立维护。
- PostgreSQL、Redis、Chatwoot storage、Qdrant 使用显式外部卷，Compose `down` 不删除数据。
- 模型、Chatwoot、Widget 和密码类运行时配置使用 `fernet:v1` 认证加密，密钥由 `CONFIG_ENCRYPTION_KEY` 独立管理。
- Redis 使用 `appendonly=yes`、`appendfsync=always` 保存已接受 Webhook；Gateway/Worker 不发布宿主机端口。

## 升级

先执行 `scripts/backup.ps1`，再执行 `scripts/update.ps1`。旧部署缺少 `CONFIG_ENCRYPTION_KEY` 时，更新脚本会在备份后生成密钥，Bridge 首次启动自动迁移旧明文运行时配置。安装/更新时会生成独立的 Adapter 入口令牌与 HMAC 密钥。角色隔离认证升级会废弃旧共享 Refresh Cookie，Admin 和 Agent 必须重新登录；Setup v1 环境还必须由 Admin 在“系统设置 → 登录安全”设置 Agent 强凭据，否则 Agent 登录会被禁用。升级后必须运行 `scripts/doctor.ps1` 和真实消息、Webhook 故障恢复、转人工、知识库检索验收。旧直连 Bridge Webhook 不会自动删除，确认 Adapter 正常后由管理员清理。失败时执行 `scripts/rollback.ps1`；需要回退数据时使用升级前备份执行 `scripts/restore.ps1`。

## 已知限制

- 仓库不内置告警通知凭证，需要接入客户自己的 Alertmanager。
- 本次开发环境只执行非破坏性验收；全新服务器安装、真实外部模型/Chatwoot/Dify 流程和破坏性恢复演练必须在隔离环境签字完成。
- Dify 数据与标准版 Qdrant 数据不自动互相迁移。
- P4-B 不支持多 Worker/多主机横向扩展；不得复制 Worker 服务或绕过 Redis 租约。
- 当前只有一个可配置 Agent 身份；多客服独立账号、邀请、停用、密码重置和细粒度 RBAC 属于后续 P4 身份体系。
- U1 本机入口验收不等于上线：真实 DNS/ACME、80/443 云防火墙、白名单外公网访问、真实 Chatwoot/模型、备份恢复和升级回滚仍需 A2 独立服务器签字。

## P4-B 验证状态（2026-09-16）

- 本机隔离确定性链路已验证默认并发峰值 8、持续 60 条/分钟、50 条突发、同会话 FIFO、503 重试隔离、串行降级和租约保护。
- 正常 SIGTERM 能优雅退出并立即释放租约；SIGKILL 后租约过期可恢复 Pending，传输重投由 Bridge 幂等收敛为一次业务效果。
- Adapter、Bridge、PowerShell、Compose、Prometheus/Grafana 和发布门禁结果以对应自动报告为准。
- 真实 AI 脚本已完成 Mock/确认门禁验证，但未在本机执行真实模式；没有 6 个专用 Chatwoot 会话时不得声称该项通过。
- A2 全新服务器真实 Chatwoot 出站事件、真实模型、备份恢复和升级回滚仍待独立服务器签字，不能由本机 P4-B 结果替代。
