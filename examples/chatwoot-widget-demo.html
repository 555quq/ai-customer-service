🔧 集成步骤

步骤 1: 在 Chatwoot 管理后台获取 Website Token
步骤 2: 将以下代码添加到你的网页 <head> 标签中
<script> (function(d,t) { var BASE_URL="http://localhost:3000"; var g=d.createElement(t),s=d.getElementsByTagName(t)[0]; g.src=BASE_URL+"/packs/js/sdk.js"; s.parentNode.insertBefore(g,s); g.onload=function(){ window.chatwootSDK.run({ websiteToken: 'YOUR_WEBSITE_TOKEN', baseUrl: BASE_URL }) } })(document,"script"); </script>
步骤 3: 配置 Webhook 连接 Bridge Service

在 Chatwoot 管理后台：
设置 → 集成 → Webhooks
URL: http://bridge-service:8000/webhook/chatwoot
事件: message_created
